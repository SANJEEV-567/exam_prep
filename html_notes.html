Introduction to HTML & Fundamental Architecture

Core Theory, DOM Tree, Tag Anatomy, Void Tags, Favicons

1. What is HTML?

HTML (HyperText Markup Language) is the standard markup language used by web browsers to structure and lay out content. It is not a programming language (no loops, memory allocation, or variables); rather, it instructs the browser rendering engine (such as Blink, Gecko, or WebKit) on how to assemble elements into the Document Object Model (DOM).

Visual DOM (Document Object Model) Tree Hierarchy
<html lang="en"> (Root Element)
<head> (Metadata)
<title> <meta> <link>
<body> (Visible Content)
<header> <main> <footer>

2. Anatomy of an HTML Tag

An HTML element is bounded by an opening tag, optional attributes, content, and a closing tag:

<p class="highlight" id="welcome"> Welcome to Coding Gita Bootcamp </p>

3. Container Elements vs. Void (Self-Closing) Elements

Classification Definition & Closing Rule Examples Common Mistakes
Container Elements Enclose text or nested child nodes. Require both opening and explicit closing tags. <p>...</p>, <h1>...</h1>, <div>...</div>, <a>...</a> Leaving tag unclosed causes broken nested formatting down the whole page.
Void Elements
(Self-Closing)		 Cannot possess any inner child nodes or content. The slash is optional in HTML5. <img>, <br>, <hr>, <input>, <meta>, <link> Writing <img>...</img> is invalid HTML syntax.

HTML Headings & Paragraph Typography

Document Hierarchy, Whitespace Collapsing, Structural Breaks

1. Heading Hierarchy (<h1> to <h6>)

Headings communicate document outline structure to search engines and screen readers. They are hierarchical, not merely aesthetic font sizes.

Live Heading Scale Preview

<h1> Coding Gita: Main Page Topic

<h2> B.Tech CSE Program Section

<h3> Full-Stack Bootcamp Module

<h4> Paid Internship Track

<h5> Career Placement Support
<h6> Student Success Records
⚠️
Golden Rule for Hackathon SEO: Exactly ONE <h1> per webpage representing the core topic. Never skip hierarchy levels (e.g., jump from <h1> straight to <h4>), as this causes accessibility audit flags.

2. Paragraphs (<p>), Line Breaks (<br>) & Horizontal Rules (<hr>)

  • Whitespace Collapsing: Browsers automatically compress sequences of multiple spaces, tabs, and carriage returns into a single whitespace.
  • <br>: Forces an inline carriage break without initiating a new paragraph block. Ideal for mailing addresses or poetry.
  • <hr>: A semantic "thematic break" separating sections, rendered as a horizontal divider line.

HTML Images, Responsive Media & Image Maps

Performance, CLS Prevention, Lazy Loading, Clickable Regions

1. Core <img> Tag & Attributes

<img src="images/campus.jpg" 
     alt="Swaminarayan University main campus building with students" 
     width="800" 
     height="450" 
     loading="lazy" 
     title="SNU Campus View">
Attribute Required? Core Functionality & Performance Impact
src Yes Relative path or absolute URL pointing to the image asset.
alt Yes Alternative text read by screen readers; rendered if image link breaks; vital for Google Image Search SEO.
width / height Recommended Pixel dimensions. Prevents Cumulative Layout Shift (CLS) by reserving aspect-ratio layout space before download completes.
loading Optional lazy (defers loading until user scrolls close to it); eager (downloads immediately; use on Hero images); auto (browser decides).
title Optional Renders a native desktop hover tooltip.

2. Responsive Images with srcset and sizes

<img src="flower-800.jpg"
     srcset="flower-400.jpg 400w, flower-800.jpg 800w, flower-1600.jpg 1600w"
     sizes="(max-width: 600px) 400px, (max-width: 1200px) 800px, 1600px"
     alt="Blooming flower" loading="lazy">

CSS Integration, Specificity & Class vs. ID

3 Styling Methods, Specificity Waterfall, DOM Selectors

1. The 3 Methods to Apply CSS

Method Declaration Location Specificity Ideal Hackathon Use Case
Inline CSS Inside tag: <p style="..."> Extremely High (1000) Quick emergency fixes, dynamic JS styles.
Internal CSS Inside <head>: <style>...</style> Standard Top pick for Hackathons! Single-file simplicity, instant live reload.
External CSS Linked file: <link rel="stylesheet" href="..."> Standard Production applications, multi-page shared styling.

2. class vs. id Attributes

Attribute Uniqueness Rule CSS Selector JavaScript Query API Targeting
class Reusable across multiple elements on the same page. .btn document.querySelectorAll('.btn') Shared components (cards, buttons, tags).
id Must be 100% unique across the whole page. #navbar document.getElementById('navbar') Singletons & anchor bookmarks (<a href="#navbar">).
💡
CSS Specificity Weight Scale:
!important (Nuclear) > Inline Styles (1000) > IDs (0100) > Classes/Attributes (0010) > Elements (0001).

Target Value Browsing Behavior Hackathon Recommendation
_self (Default) Opens in the same browser tab, replacing current page. Default internal site navigation.
_blank Spawns link in a brand new tab/window. Always pair with rel="noopener noreferrer".
_parent / _top Breaks out of current iframe or frameset into top window. Used inside embedded widgets.

Hackathon File Upload Trap: If your form contains an <input type="file">, you MUST set enctype="multipart/form-data" and method="POST" on the parent <form> tag! Otherwise, file binaries are stripped out during submission.

2. Top 10 Common HTML Mistakes That Cost Hackathon Points

  1. Missing alt attribute on <img>: Instant failure on accessibility (a11y) audits.
  2. Multiple <h1> tags: Breaks document hierarchy and harms SEO ranking scores.
  3. Omitting name attributes on form inputs: Causes the backend to receive empty payloads!
  4. Missing enctype="multipart/form-data" on file forms: File uploads silently fail.
  5. Autoplaying videos without muted: Modern browsers completely block unmuted playback.
  6. Using stacked <br><br><br> for layout spacing: Use CSS margin or gap instead.
  7. Duplicate id values on one page: Breaks document.getElementById() in your JavaScript logic.
  8. Nesting block elements inside inline tags: Putting a <div> inside a <span> produces invalid DOM trees.
  9. Using deprecated attributes like border="1" or align="center": Always style with modern CSS.
  10. Using target="_blank" without rel="noopener noreferrer": Exposes the parent page to tab-napping exploits.
