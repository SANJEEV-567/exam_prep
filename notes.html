1. Executive Overview & Zero-JavaScript Architectural Philosophy

The SurplusLink Bakery Rescue prototype was engineered strictly following a Zero-JavaScript constraint. In contemporary web development, client-side frameworks often deploy megabytes of script runtime merely to toggle menus, tabs, and modals. This introduces hydration lag, garbage collection pauses, and potential runtime crash vectors.

This project proves that advanced declarative CSS3 combined with semantic HTML5 form primitives provides a deterministic, hardware-accelerated user experience with 60 FPS transitions, zero memory leaks, and native accessibility.

Core Engineering Guarantees

  • Zero Script Tags: 0 <script> tags, 0 inline event listeners (onclick, onload, onsubmit), and 0 external JavaScript libraries across all 18 views.
  • Modular Single-Responsibility: Exactly 1 HTML view paired with 1 dedicated stylesheet (e.g., index.html + index.css, radar.html + radar.css).
  • Deterministic State Machine: Interactive menus, tabs, and step flows are driven purely by the Checkbox & Radio Hack using :checked and the sibling combinator (~).
  • Mobile-First Progressive Enhancement: Baseline styles render fluidly on mobile viewports (<600px); tablet and desktop experiences are layered via min-width media queries.
  • 100% Authentic Assets: Direct vector SVGs and extracted Figma imagery with zero external CDN dependencies or placeholder URLs.

2. Architectural Flowchart: Pure CSS State Machine Engine

The diagram below illustrates the complete lifecycle of state mutation without JavaScript runtime intervention. Form control binding natively toggles the boolean state of an invisible input element, prompting the browser's CSS selector engine to recalculate computed styles across target sibling nodes.

Theoretical Mechanics of Declarative State Mutation

A pure CSS state machine is formally modeled as a Deterministic Finite State Machine (DFSM): M = (Q, Σ, δ, q₀, F) where states Q = {Unchecked, Checked}, input Σ = {Pointer Tap}, and the transition function δ maps directly to browser user-agent event loops.

HTML Declarative Structure 
<!-- 1. Hidden State Switch -->
<input type="checkbox" id="nav-toggle" class="drawer-toggle">

<!-- 2. Accessible Tappable Trigger -->
<label for="nav-toggle" class="drawer-trigger">
  <span>App Screens Menu</span>
</label>

<!-- 3. Target Sibling Container -->
<div class="drawer-overlay">
  <label for="nav-toggle" class="drawer-backdrop"></label>
  <nav class="drawer-menu">...</nav>
</div>
CSS Sibling Resolution 
/* Initial State: Hidden off-canvas */
.drawer-overlay {
  visibility: hidden;
  opacity: 0;
  transition: opacity 0.3s ease, visibility 0.3s ease;
}
.drawer-menu {
  transform: translateX(100%);
  transition: transform 0.3s cubic-bezier(0.16, 1, 0.3, 1);
}

/* Mutated State via :checked sibling combinator */
.drawer-toggle:checked ~ .drawer-overlay {
  visibility: visible;
  opacity: 1;
}
.drawer-toggle:checked ~ .drawer-overlay .drawer-menu {
  transform: translateX(0); /* 60 FPS GPU Composite */
}

7. Responsive Design Theory & Breakpoint Architecture Flowchart

The responsive layout is built strictly on a Mobile-First Progressive Enhancement strategy. Rather than authoring heavy desktop layouts and attempting to compress them down with fragile max-width queries, base CSS styles exclusively target small touchscreens (< 600px). Tablet and desktop layouts are progressively unlocked via min-width queries.

Mobile Tier (< 600px)

Default Baseline

Single-column flex stack with 100% fluid width. Zero letterboxing or horizontal clipping. Modals slide up as bottom sheets with drag handles. Bottom navigation bar is anchored to viewport bottom.

Tablet Tier (600px – 1024px)

@media (min-width: 600px)

Padded background with dual-tone gradient wash. The application container morphs into an elevated floating device frame with rounded corners and multi-column card grids.

Desktop Tier (> 1024px)

@media (min-width: 1024px)

Viewport is constrained to an authentic mobile device shell (max-width: 440px) centered horizontally, surrounded by a soft radial backdrop light wash. Micro-interaction hover lifts are enabled.

8. Deep Theoretical Foundations of Modern CSS

Box Model Invariance

The universal rule *, *::before, *::after { box-sizing: border-box; } fundamentally alters the default W3C box model. Padding and borders are consumed inwardly, guaranteeing that width: 100% elements never produce unexpected horizontal scrollbar overflows.

Stacking Contexts & Compositing Layers

Elements with position: fixed or properties like transform, backdrop-filter, and z-index form isolated stacking contexts. The browser engine promotes them to dedicated GPU compositing layers, eliminating expensive main-thread layout reflows.

Accessibility & Semantic Outline

By utilizing semantic HTML5 landmarks (<main>, <nav>, <header>, <article>) instead of unsemantic <div> trees, assistive screen readers construct a clean accessibility tree, allowing keyboard navigation to jump directly between landmarks.
